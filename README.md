# Muhammad Zain Abbas Portfolio

Personal developer portfolio for Muhammad Zain Abbas, a full-stack developer
focused on modern web platforms, real-time communication, and practical AI
integration.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- React Three Fiber and Drei
- Lucide icons

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Validation

```bash
npm run lint
npm run build
```

## Deploy on Vercel

1. Push this repository to GitHub.
2. Open [Vercel New Project](https://vercel.com/new).
3. Import the GitHub repository.
4. Keep the detected Next.js defaults.
5. Select **Deploy**.

The project does not require environment variables for the current static
portfolio build.
