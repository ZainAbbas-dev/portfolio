# Muhammad Zain Abbas | Developer Portfolio

A modern personal portfolio showcasing my work as a full-stack developer focused
on production-ready web applications, real-time communication, and practical AI
integration.

**Live Website:** [portfolio-gilt-pi-66.vercel.app](https://portfolio-gilt-pi-66.vercel.app)

## Overview

This portfolio presents my featured projects, technical skills, education,
professional certificates, and contact details in a polished responsive
interface. It is designed to give recruiters and collaborators a clear view of
my experience across the MERN ecosystem, Next.js, Python, and applied AI.

## Highlights

- Responsive dark glassmorphism interface
- Animated hero section with an interactive 3D scene
- Featured project cards with live application links
- Full-stack, database, AI, and real-time technology showcase
- About, education, certifications, and developer community sections
- Downloadable resume
- Contact form with a prefilled email workflow
- Accessible reduced-motion support

## Run Locally

```bash
git clone https://github.com/ZainAbbas-dev/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Validation

```bash
npm run lint
npm run build
```

## Project Structure

```text
src/
|-- app/              # App Router pages, layout, and global styles
|-- components/       # Portfolio sections and shared UI
|   `-- 3d/           # Three.js hero scene
`-- data/             # Project and skill data

public/
`-- images/           # Resume and profile assets
```

## Deployment

The application is deployed on Vercel from the `main` branch. The current
portfolio does not require environment variables.
